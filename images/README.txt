Course photos live in this folder, one per course, named after the course's slug
(for example blue-hill.jpg). Each was taken from the course's own website (or
Bergen County Golf / NY State Parks for those courses) and is used with the
course's permission, granted October 2026.

To replace one: save the new photo here under the same name (landscape, about
1600px wide), and update that course's photoCredit in js/data.js.
